Algorithm Theory

How it Works

Linear search operates by iterating through a collection of elements, starting from the first index, and examining each item one by one.

The algorithm only terminates when the target value is found, or the pointer successfully traverses the entire array without finding a match.

Time Complexity

Performance scales directly with the size of the array (N).

  • Best Case: O(1)
    The target is the very first element checked.
  • Worst Case: O(N)
    The target is the last element, or doesn't exist.
  • Average Case: O(N)
    On average, half the array needs to be checked.

Space Complexity

Complexity: O(1) Constant Space

Linear search is extremely memory efficient. It operates "in-place", meaning it directly reads the existing array structure.

It only requires a single independent variable (the moving pointer) to track its progress.
